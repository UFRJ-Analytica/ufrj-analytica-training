● Evento: Acordos de Cessar-Fogo (Ceasefire) em zonas de conflito.

● Pergunta: Boatos especulativos de cessar-fogo causam um pico anormal de injeção de capital?

● Hipótese: Mercados de cessar-fogo (ceasefire) são extremamente suscetíveis a falsos positivos: um boato diplomático surge, a probabilidade dispara impulsionada por investidores especulativos e, horas depois, um porta-voz oficial nega o acordo, fazendo o mercado desabar. Notícias não confirmadas sobre tréguas causam picos de volume que desviam significativamente da média histórica recente (identificáveis via Z-Score). Investidores que entram nesses topos sofrem perdas quando a probabilidade sofre um "crash" após o desmentido.

● Tabelas utilizadas: polymarket_optimized(markets e trades) e polymarket_mart(daily_market_stats).

● Período analisado: 20/04/2026 até 01/05/2026.

● Descrição: As consultas SQL exploratórias mapearam a base de dados para entender eventos geopolíticos, calculando o volume e a amplitude de preços para provar que acordos diplomáticos geram volatilidade após o anúncio oficial. Para monitorar esse comportamento crítico, o sistema de alertas consolidados utiliza janelas deslizantes de 24 horas que combinam o Alerta 1, focado em entradas atípicas de capital via Z-Score, o Alerta 2, focado em quedas bruscas de probabilidade, e o Alerta Duplo, que sinaliza anomalias extremas pela ocorrência simultânea de ambos os gatilhos.
